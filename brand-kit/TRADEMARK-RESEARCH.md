So this is a **web-index search**, not a substitute for the official search.
- **Before any filing, the official searches must be run:** IP India "Public Search" (Trade Marks section) and the USPTO Trademark Search (tmsearch.uspto.gov), checking exact "Minvana" plus phonetic/visual similars (Minwana, Minvanna, Minvanaa) in the relevant classes.

### What web-index searches found
- **India:** No registered or pending "Minvana" trademark surfaced in any indexed trademark source. The only commercial use found is **soshai.in**, an Indian clothing site listing a product named "MINVANA" (a sold-out evening gown, product code SBS-153). That's an unverified common-law product name in apparel — a different field from media, and no registered mark was found behind it. It is not a blocker for Classes 41/9/35, but it's worth knowing about if merch (Class 25) is ever pursued.
- **US:** No "Minvana" mark surfaced in USPTO-indexed records. Nearest indexed hits are unrelated: "Minerva Associates" (inventory software, Class 9) and "The Mina Group" (restaurant group) — visually and phonetically distinct, different fields.
- **Other:** "Mirava" (a mobile-app pricing platform, mirava.io) — different word, no conflict.

### Verdict
**"Minvana" looks clear in both India and the US based on everything publicly indexed** — no identical or confusingly similar registered mark found. The brand name is invented/coined (minute + nirvana), which is exactly the kind of mark registries like: distinctive, non-descriptive, hard to object to under absolute grounds. Final clearance still requires the official database searches above.

## 3. Filing process

### India (priority — primary audience is India)
1. **Clearance search** — IP India Public Search (wordmark + phonetic) in Classes 41, 9, 35 (+38 if added). Free.
2. **Decide applicant** — individual (Amandeep Singh Ghotra) is simplest and gets the concessional fee. Can be assigned to a company later if Minvana incorporates.
3. **Prepare documents** (see checklist §6).
4. **File Form TM-A online** via the IP India e-filing portal (Trade Marks section). Pay fee per class. You immediately get an **acknowledgment with an application number** — from this moment you may use **™** on the brand.
5. **Vienna codification** (for logo/device marks) — registry classifies the figurative elements. Automatic.
6. **Examination** — examiner reviews under §9 (absolute grounds: is it distinctive?) and §11 (relative grounds: conflicts with existing marks). Typically **6–12 months** to first examination report.
7. **First Examination Report (FER)** — if objections are raised, reply in writing within **30 days** (extensions possible). Most applications get at least a routine objection; a reply usually clears it.
8. **Show-cause hearing** (only if the reply doesn't satisfy the examiner) — argue in person/video or through attorney.
9. **Accepted & Advertised** — mark is published in the **Trade Marks Journal**. **4-month opposition window** — anyone may oppose.
10. **Registration** — if unopposed (or opposition won), the **Registration Certificate** issues. You may now use **®**. Valid **10 years from the application date**, renewable indefinitely in 10-year blocks.

### United States (secondary — file later unless US conflicts appear)
1. Clearance search on USPTO Trademark Search + common-law web search.
2. File via **TEAS** (Trademark Electronic Application System): **TEAS Plus ($250/class)** if your goods/services match USPTO's pre-approved ID Manual wording; **TEAS Standard ($350/class)** if you need custom wording. Plus is cheaper and tends to move faster but is stricter.
3. Choose filing basis: **1(a) use in commerce** (already used — Minvana Shorts/blog are live since 2026-09-30) or **1(b) intent-to-use** (for the not-yet-built app).
4. USPTO examination → office actions (respond within 3 months, extendable) → approval → **30-day opposition window** (published in the Trademark Official Gazette).
5. If 1(a): registration issues. If 1(b): **Notice of Allowance**, then file **Statement of Use ($100/class)** within 6 months (extendable to 36 months at $125 per 6-month extension) once the app launches → registration.
6. Maintenance: **§8 declaration of use at years 5–6**, renewal every 10 years.

## 5. Typical timelines

### India
| Stage | Typical time |
|-------|--------------|
| Filing → acknowledgment number | Immediate (same day) |
| Examination / First Examination Report | ~6–12 months |
| Reply to objections | 30 days from FER |

| Acceptance → advertised in Trade Marks Journal | ~4–6 months after clearance |

| Office-action responses | 3 months each (extendable) |

| Intent-to-use → Statement of Use deadline | 6 months after allowance, extendable to 36 months |

In both countries you may use **™ from the filing date**; **® only after registration**.
